# 独立审核后的修订与验证

日期：2026-10-31。对应 skill 1.1 / 新账本 schema 2。旧的 [v1 验证记录](validation.md)与产物保持可查；这里记录实际发现、修正及仍未验证的部分。

## 为什么这次修改

独立审核指出了一个实质问题：自我修正示例的数字和定位虽然正确，却漏掉 Huang 等的主结果，只突出提示混杂；CRITIC 无工具消融也只提取了部分正行。**正确的局部引用并不保证公平的整体判断。** 因此，这次首先修正来源提取，再加强机器检查。

审核还给出了对抗账本、字段随机篡改和一组虚构文献包对照。修订前已复现所列探针被旧检查器放过，以及 `access` 为列表/对象导致的 TypeError。对照只有单次观察，未显示稳定质量优势，且使用 skill 的执行更重；不能据此宣称 skill 无效，也不能继续暗示比较优势。

## 采纳、限定与保留

| 反馈 | 本次处理 | 边界 |
|---|---|---|
| 漏掉决定性主结果 | 先记录主论点、关键结果位置、覆盖或遗漏原因；重查三篇历史论文 | 字段齐全仍不证明它真是主结论，必须人工对照原文 |
| 改标签重复计数 | URL/DOI 规范化、同版本身份去重、同名与共享作者/数据/代码提示；独立数量约束 | 隐藏或改写身份、来源家族仍能绕过；不能自动发现所有共享来源 |
| 类比冒充直接支持 | 只有 analogy 用途的证据进入 context；支持/反证/区间不确定/上下文/线索列表互斥 | 逻辑范围与迁移假设仍需语义审阅 |
| 状态与关系不一致 | 检查 convergent 数量、contested 反证、superseded 现用、关系端点、冲突证据状态、预算及日期 | 不把标签一致性当科学真伪判定 |
| 关系仅引用端点 | 缺少关系自身 `source_locator` 时提示；原文支持与分析假设分开 | **不自动将两端作为比较证据判为循环论证**；这可以是合法的跨研究比较 |
| 异常输入崩溃 | 枚举类型保护、URL 异常处理、有限数值/区间检查与变异测试 | 非形式化证明，也未穷举任意嵌套或资源耗尽输入 |
| 综合标签过粗 | 增加 refuted、uninformative、uncertain_claim_ids；记录 inherited_threats | 反驳必须限定命题；宽区间不等于零效应；共用代码不等于确定继承 bug |
| 字段漂移 | 已知嵌套结构的未知字段给 caution | 允许有说明的扩展，未验证扩展本身 |
| Scout 太重 | 默认短判断，最小账本只要四类记录；单独提供小型格式参考 | 尚未测得 token/延迟下降或质量提升 |

此外，只有实际记录两轮连续、无决策变化的扩展，才能声明 decision_saturation；预算耗尽和离线材料用尽不需要虚构扩展轮次。

## 真实论文示例重查

本次打开三篇主来源，并核对相关方法、主结果块及消融：

- Huang 等：§3 Tables 2–3 的 intrinsic/oracle 区分，§3.1 样本分母，§4 Table 7 的同回答数比较；没有把回答数匹配写成总 token 匹配。
- CRITIC：§2 与 §4.2 Table 2 的工具方法及完整正负无工具行；Appendix D.6 复用结果保持旧来源家族。
- Self-Refine：§2–3/Table 1 的主要方法与任务异质性；数学小收益没有被扩写成普遍无效。

[修正版报告](../examples/self-correction/report.md)与[账本](../examples/self-correction/evidence.json)保留 C1–C4，增加主结论与缺失结果，替换旧的宽泛命题。旧例完整保存在 [example-v1](runs/example-v1)，不将历史产物改写成从未犯错的样子。

这次没有重新做当前领域的在线检索、完整前向引文或性能复现。原文内容与表内点估计的核对，不能替代统计推断或对现代模型的实测。

## 独立 Scout 行为检查

输入：[七项虚构 speculative-decoding 文献材料](fixtures/speculative-decoding.md)。请求是为 T-7 chat、batch=1、同一 GPU 和精确输出分布要求选择两篇精读，并判断 adaptive γ 是否值得做原型。执行 agent 仅收到 skill、原始材料和请求；未提供测试、旧产物、审核结论或预期答案。输出写入独立临时目录后归档。

[第一轮产物及运行说明](runs/scout-initial/run-notes.md)正确处理了勘误、共享来源、宽区间、类比和摘要，但读取了四份 skill 资源，首次字段/枚举有误后又通过完整合同修复。这是实际使用摩擦，不能将最终零错误当成一次生成即成功。

据此增加 `scout-format.md`：精确枚举、嵌套字段及可执行检查的小型完整例子；入口明确将普通保存 Scout 路由到这一份参考。[第二轮独立产物与运行说明](runs/scout-compact/run-notes.md)中，agent 使用小型格式参考，并为具体诊断按需打开 contradictions；没有加载完整 evidence-method/output-contract。账本只包含七项来源、八条论点及阅读队列，第一次运行检查器即 0 errors / 0 cautions，无后续字段修复。

两次试用均优先 P2/P4，保留 P3 正结果和未知继承风险，将勘误后的宽区间保留为不确定，未将 code/chat 的相反点估计制造成可比冲突；也未凭摘录保证精确分布。第二轮 P5 选择 defer 而非 exclude，但两次均明确其无新增独立实验。这说明本例中的核心判断可用，不表明这些阅读选择在其他语料上最优。

归档只规范化机器绝对来源路径以便公开移植；不修改 agent 的科学判断。虚构材料不能当成真实论文引用。行为检查没有计量可靠 token/延迟，也没有把多次开发反馈当成互相独立的质量样本。

## 仍未解决的验证问题

- 真实开放检索是否漏掉重要历史转折或近期反例：未建立召回基准。
- 在相同任务、输入、预算与模型下是否优于普通 agent：没有多轮盲评对照。
- Scout 是否稳定节省成本，且保持判断质量：仍需单独测量。
- 语义蕴含、主结果完整性、真实来源独立性：检查器无法认证，标签伪造仍可能通过。
- 跨模型和其他 agent 宿主的效果、自动 skill 触发率：未独立评测。

下一步最有价值的评测是固定真实研究问题和预算，盲评关键遗漏、错误关系、重复证据误计、阅读选择和决策变化，同时记录总成本。当前修订把已观察失败变成回归材料；尚不构成性能提升证明。
